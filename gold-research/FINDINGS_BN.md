সময়: শুধু **২০২৫-০১-০১ থেকে ২০২৬-০৭-৩০** বিচার করা হয়েছে। ২০২৪-০৬..১২ শুধু শেখার জন্য (warm-up)।

## ভাগ ১ — মূল সংজ্ঞা ও সূত্র

| নাম | সূত্র |
|---|---|
| ATR(TF) | MT5-এর মতো: TR = max(H−L, \|H−C₋₁\|, \|L−C₋₁\|); ATR14 = TR-এর ১৪ বারের সরল গড় |
| MAE, MFE (একটা সিগন্যালের) | সিগন্যালের পর নির্দিষ্ট সময়ে (horizon) দাম বিপক্ষে / পক্ষে সর্বোচ্চ কত গেছে ÷ ATR |
| বাজার-মাপা স্টপ গুণক kq | kq = quantile_q( শেষ ৬০টা **শেষ-হওয়া** সিগন্যালের MAE ); স্টপ = kq × ATR। k50, k70, k90 = q 0.5/0.7/0.9 |
| বাজার-মাপা লাভ fq | fq = quantile_q( শেষ ৬০টা শেষ-হওয়া সিগন্যালের MFE ) ATR এককে; TP1 (R-এ) = fq / kq |
| H4 trail (Assay) | প্রতি H4 ক্লোজে: স্টপ = সর্বোচ্চ দাম − quantile_q(শেষ ২০টা H4 ট্রেন্ড-পর্বের গভীরতম পুলব্যাক) × ATR(H4) |
| 6-EMA stack | EMA30>EMA35>EMA40>EMA45>EMA50>EMA60 = +1 (উল্টো = −1, নইলে 0) |
| ট্রেন্ড-মান (Daily) | v = \|Close − EMA50\| / ATR14 (Daily); ট্রেন্ড-মান = গত ২৫০ দিনের মধ্যে আজকের v-এর শতাংশ-অবস্থান (০..১) |
| পতন-মান | max(0, ১ − DD% / ২০) |
| ঝুঁকি % (Assay) | Min + (Max − Min) × পতন-মান × ট্রেন্ড-মান; fade-এ (১ − ট্রেন্ড-মান) এবং × ০.৫ |
| pctrank500(x) | x-এর বর্তমান মান তার নিজের শেষ ৫০০ বারের মধ্যে কোন শতাংশে (০..১) — বাজার-অনুযায়ী সীমা, স্থির সংখ্যা নয় |
| Profit ratchet (q, keep) | খোলা লাভ ≥ fq/kq R হলে: স্টপ ≥ এন্ট্রি + keep × (সর্বোচ্চ দাম − এন্ট্রি) |
| Breakeven be1 | লাভ ≥ ১R হলে স্টপ = এন্ট্রি + ০.০৫R |
| Equity সরলতা (eq R²) | ক্রমিক equity বনাম ট্রেড-ক্রমের সরলরেখার R² (১ = পুরো সোজা) |
| সেরা ৫ দিনের ভাগ | সেরা ৫ দিনের লাভ ÷ মোট লাভ (কম = আয় ছড়ানো) |

## ভাগ ৬ — চূড়ান্ত সুপারিশ: প্রতিটা strategy-র পূর্ণ নিয়ম (সূত্র আকারে)

চিহ্ন:
- C, H, L, O = বারের ক্লোজ, হাই, লো, ওপেন
- ATR = সেই TF-এর ATR14 (MT5)
- dir = +1 লং, −1 শর্ট
- E = এন্ট্রি দাম
- lvl = সিগন্যাল বারের ক্লোজ
- R = স্টপ দূরত্ব
- best = এন্ট্রির পর পক্ষে সর্বোচ্চ (লংয়ে সর্বোচ্চ High, শর্টে সর্বনিম্ন Low)
- peak = (best − E) × dir ÷ R

- CONF: উঁচু TF-এর stack = dir
- সেশন: UTC ৭–২০

## ভাগ ১০ — অর্ডার-ফ্লো (টিকের কেনা-বেচার চাপ)

**ডেটা:** GC-র প্রতিটা ট্রেড-প্রিন্ট (২০২৪–২০২৬, ~৯ কোটি)। প্রতিটায় আক্রমণকারী পক্ষ (B = মার্কেট-অর্ডারে কেনা, A = মার্কেট-অর্ডারে বেচা) আর আকার আছে। সেখান থেকে ১-মিনিটের order-flow বার।

| মাপ | সূত্র (k = ৫/১৫/৬০/২৪০/১৪৪০ মিনিট) |
|---|---|
| delta_k | (Σ কেনা ভলিউম − Σ বেচা ভলিউম) ÷ Σ ভলিউম, ট্রেডের দিকে ধনাত্মক |
| bigdelta_k | একই হিসাব, শুধু ≥১০ লটের প্রিন্ট |

| absorb_k | log(ভলিউম_k) − log(\|দামের পরিবর্তন_k\|): বেশি ভলিউম কিন্তু দাম কম নড়া |
| volrate_k | গত k মিনিটের প্রতি-মিনিট ভলিউম ÷ গত ৫ দিনের গড় |

**পুরো সময় একসাথে দেখলে (৬–৭ কোয়ার্টারের প্রায় সবগুলোয় একই দিক):**
- **S1:** গত ২৪ ঘণ্টায় বড় খেলোয়াড়রা আগেই ট্রেডের দিকে জোরে কিনে/বেচে থাকলে খারাপ। IC −০.২৩; নিচের ভাগে +০.৫৬R, উপরের ভাগে −০.১৩R।
- **S4:** একই ধরন (delta1440, delta60)।
- **S7:** দাম আর flow-এর অমিল (div60) খারাপ।
- **F9, F10:** আগের ৪–২৪ ঘণ্টায় বড় চালের পর fade ভালো।
- **S2, S3, S5, S6, F8:** কোনো ধারাবাহিক প্রভাব নেই।

**সৎ (causal) পরীক্ষা:** প্রতি মাসে শুধু অতীত দেখে খারাপ অংশ (নিচের বা উপরের ২০%) বাদ দেওয়া হয়েছে।
- প্রতিটা strategy-তে ৩৮টা মাপের মাত্র ০–৫টা লাভ আর পতন দুটোই ভালো করে। এটা ভাগ্যের সমান।
- উন্নতি মাত্র কয়েক R।

→ **অর্ডার-ফ্লো দিয়েও লসের ট্রেড আগে থেকে নির্ভরযোগ্যভাবে চেনা যায় না।**
