# Assay_Lab.mq5 — ল্যাবের ফাইন্ডিংস বসানো সংস্করণ

আপনার আসল `Assay.mq5` অপরিবর্তিত আছে। এটা আলাদা কপি। কম্পাইলের জন্য একই `Include/Assay/*.mqh` ফাইলগুলো লাগবে।

## নতুন spec-চাবি (যেকোনো Slot-এর লেখায় যোগ বা মুছে চালু-বন্ধ করা যায়)

| চাবি | কাজ | ফাইন্ডিং |
|---|---|---|
| `QTP=0` | TP1-এর আংশিক বন্ধ আর লক বন্ধ | ৯ |
| `TP=3` | পুরো পজিশন E + ৩R-এ বন্ধ (broker TP) | ৮, ১০ |
| `BE=1,0.05` | +১R লাভ হলে SL = E + ০.০৫R | ১৪ |
| `GB=1,0.5` | শিখর ≥১R হওয়ার পর লাভ শিখরের ৫০%-এর নিচে নামলে বের | ১৫ |
| `RAT=0.9,0.5` | লাভ সাম্প্রতিক সিগন্যালের ৯০তম শতাংশ-লাভ ছুঁলে SL অন্তত অর্ধেক লাভ ধরে রাখে | ১৬ |
| `ATRC=4` | প্রতি টিকে SL = সর্বোচ্চ দাম − ৪ × ATR(slot TF) | ১২ |
| `H4ST=1` | H4 6-EMA stack ট্রেডের দিকে না থাকলে ট্রেড বাদ | ২০ |
| `ADXQ=0.8` | H1 ADX এই slot-এর অতীত সিগন্যালের ৮০তম শতাংশের বেশি হলে ট্রেড বাদ | ১৯ |
| `TPMEAN=1` | fade-এর TP = ২০-বারের গড় (SMA20) | ২৯ |
| `W=0.5` | এই slot-এর ঝুঁকি অর্ধেক | ৩২ |

বাদ পড়া সিগন্যালও বাজার-মাপে (স্টপ, TP) যোগ হতে থাকে, শুধু ট্রেড নেওয়া হয় না। প্যানেলে "skipped: ..." কারণ দেখা যায়।

## ডিফল্ট সেটিং (টিক-যাচাই করা, ২০২৫-০১..২০২৬-০৭)

| Slot | পরিবর্তন | টিক-ফল: আগে → পরে |
|---|---|---|
| S1 | নেই | +৩১R |
| S2 | QTP=0; TP=3; BE=1,0.05 | +৮৯R / ১১ লাভের মাস → +৬৭R / ১৫ মাস, পতন ৫.৩ → ৪.১R (লাভ কম, কিন্তু মসৃণ) |
| S3 | TP=3 | +৫২R → +৫২R, লাভের মাস ১৫ → ১৭/১৯ |
| S4 | QTP=0; QTR=0; ATRC=4; H4ST=1 | +৩২R / পতন ৩.৬ → +২৯R / ২.১, লাভের মাস ১২ → ১৫ |
| S5 | নেই | +৬১R |
| S6 | QTP=0; TP=3; BE=1,0.05; W=0.5 | +৫১R → +৯০R (পূর্ণ ঝুঁকিতে) |
| S7 | চালু; QSL=0.5; QTP=0; RAT=0.9,0.5; ADXQ=0.8; W=0.5 | বন্ধ ছিল → +৯২R, পতন ৬R |
| F8 | QSL=0.5 | +২০R → +৫০R-এর কাছাকাছি |
| F9 | HOR=1440; QTP=0.7; BE=1,0.05 | +১৩R → +১৮R |
| F10 | TPMEAN=1 | +৯R → +১৫R |
| F11 | W=0.5 | +৫R |

পুরো পোর্টফোলিও, টিক-ডেটায়: +৩৩৫R → ~+৪২০R, পতন ১৯.৬ → ~১৩R, লাভের মাস ১৫ → ১৮/১৯।

**আগের মতো ফিরতে:** কোনো slot-এর লেখা আসল `Assay.mq5`-এর লেখা দিয়ে বদলে দিন।
