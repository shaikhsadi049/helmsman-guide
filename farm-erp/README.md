# খামার ERP — বাংলাদেশের সমন্বিত খামারের জন্য

লেয়ার, ব্রয়লার, সোনালি, দেশি মুরগি, হাঁস, কোয়েল, কবুতর, টার্কি, তিতির, গরু, মহিষ,
ছাগল, ভেড়া, খরগোশ ও মাছ — সবই একই সিস্টেমে, কারণ বাংলাদেশের খামারি একসাথেই পালেন।

## কেন

বাংলাদেশে লক্ষাধিক বাণিজ্যিক খামার চলে খাতা-কলম আর Excel-এ। প্রতি ব্যাচের আসল খরচ
কত, FCR কত, কোন শাখায় লস হচ্ছে — বেশিরভাগ খামারি জানেন না। আর তাঁরা প্রায় সবাই
**সমন্বিত খামারি**: একই উঠানে মুরগি, গরু, ছাগল, হাঁস; একটাই ক্যাশবাক্স।

তাই শুধু ব্রয়লারের সফটওয়্যার কাজে লাগে না — কিন্তু প্রতিটা প্রাণীর জন্য আলাদা মডিউল
লিখলে প্রকল্প শেষও হয় না। এই প্রকল্পের কেন্দ্রীয় ধারণা:

> প্রজাতিভেদে স্ট্রাকচার বদলায় না, মেট্রিক বদলায়।

একটাই উৎপাদন ইউনিট টেবিল, একটাই চলাচলের খাতা, একটাই দৈনিক লগ — আর কনফিগ টেবিল
ঠিক করে দেয় কোন প্রাণীর জন্য কী প্রযোজ্য। নতুন প্রাণী যোগ করা মানে নতুন সারি,
নতুন কোড নয়।

## চালানো

দরকার: PostgreSQL 13+ (16 এ পরীক্ষিত)

```bash
cd farm-erp/db
./build.sh                  # শূন্য থেকে বানায় ও পরীক্ষা করে
DB=farmerp_dev ./build.sh   # অন্য নামে
./build.sh --no-seed        # শুধু স্কিমা
```

বিল্ড ধাপে ধাপে: স্কিমা → মাস্টার ডেটা → কনভেনশন যাচাই → স্মোক টেস্ট → RLS টেস্ট।
যেকোনো ধাপ ব্যর্থ হলে থামে।

## মূল ডিজাইন সিদ্ধান্ত

| সিদ্ধান্ত | কেন |
|---|---|
| UUIDv7 প্রাইমারি কী | অফলাইনে তৈরি করা যায়, আবার সময়-ক্রমানুসারী তাই ইনডেক্স দ্রুত |
| ব্যাচ ও একক প্রাণী একই টেবিলে | একবার লিখলেই সব প্রজাতির জন্য কাজ করে |
| মেট্রিক-চালিত দৈনিক লগ | প্রজাতিভেদে আচরণ কনফিগ থেকে, `if-else` থেকে নয় |
| `current_qty` কলাম নেই | সংখ্যা চলাচলের যোগফল থেকে — অমিল হওয়া অসম্ভব |
| মড়ক দৈনিক লগে নয় | স্টকের একটাই সত্য: চলাচলের খাতা |
| চলাচল অ্যাপেন্ড-অনলি | ভুল হলে উল্টো এন্ট্রি, কাটাকুটি নয় |
| RLS + FORCE, fail-closed | প্রসঙ্গ বসাতে ভুললে ফাঁকা ফলাফল, অন্যের ডেটা নয় |
| অডিট কলাম ট্রিগার বসায় | ১৫০ টেবিলে হাতে লিখলে কোথাও বাদ পড়বেই |
| `99_verify.sql` CI-তে | কনভেনশন নথিতে লেখা থাকলে ভাঙে; যাচাইয়ে থাকলে ভাঙে না |

## সতর্কতা

`seed/08_vaccine.sql` এর টিকার সূচি **নির্দেশক**, চিকিৎসা-পরামর্শ নয়। প্রকৃত সূচি
নির্ভর করে হ্যাচারি কী দিয়েছে, এলাকার রোগের চাপ ও টিকার ব্র্যান্ডের উপর। প্রতিটা
খামারে নিবন্ধিত পশুচিকিৎসক বা উপজেলা প্রাণিসম্পদ কর্মকর্তার পরামর্শে চূড়ান্ত করুন।

`seed/04_breed.sql` এর ফলনের সংখ্যাগুলোও নির্দেশক — প্রকাশিত ব্রিড স্ট্যান্ডার্ড ও
মাঠপর্যায়ের গড়ের কাছাকাছি। কয়েক ব্যাচ পরে খামারির নিজের বাস্তব ফলনই বেশি
নির্ভরযোগ্য মানদণ্ড হবে।
